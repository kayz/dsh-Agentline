# AgentLine UI Mockups

静态 HTML 模拟页，用于评审 AgentLine 插件的三阶段驾驶舱 UI/UX。

- `index.html`：首页 / Studio / Blueprint / Build / 设置五个页面。
- 纯静态：不连接后端，不调用 CLI，不修改 `.collab`。
- 数据为 mock，只反映 `design-v1.md` §5 的界面设计，不代表最终实现。
- 设计仍有契约 blocking（见 `../status.md`）；本 mockup 只用于确认布局、信息层级和交互方式。

打开方式：直接用浏览器打开 `index.html`。
